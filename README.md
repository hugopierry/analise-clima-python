# 🌦️ Sistema de Consulta de Clima e Tempo em Python

## 📌 Sobre o projeto

Este projeto consiste em um sistema desenvolvido em Python que consulta uma API de clima e tempo para obter informações meteorológicas atualizadas e apresentá-las diretamente no terminal.

O objetivo principal é praticar o consumo de APIs, a obtenção de dados externos e o desenvolvimento de aplicações em Python.

## ⚙️ Funcionalidades

Ao executar o programa, são exibidas as seguintes informações:

- 🌡️ Temperatura atual;
- 🌡️ Sensação térmica;
- 💧 Umidade relativa do ar;
- 🕒 Data e hora da última atualização;
- 🌤️ Descrição das condições meteorológicas, como céu encoberto, tempo chuvoso e possibilidade de pancadas de chuva.

## 🛠️ Tecnologias utilizadas

- **Python** — desenvolvimento da aplicação;
- **API meteorológica** — obtenção dos dados climáticos;
- **Requests** — realização de requisições HTTP, caso utilizada no projeto.

## ▶️ Como executar

1. Clone este repositório para sua máquina.
2. Instale as dependências necessárias.
3. Execute o arquivo principal do programa pelo terminal.

Exemplo:

```bash
python main.py
```

*Observação: substitua `main.py` pelo nome do arquivo principal utilizado no projeto.*

## 🎯 Objetivo de aprendizado

Este é um projeto de prática desenvolvido para consolidar conhecimentos em Python e compreender, na prática, como consumir APIs e transformar dados recebidos em informações apresentadas ao usuário.

Apesar de simples, o projeto representa mais um passo no meu aprendizado em programação e no desenvolvimento de aplicações que utilizam dados externos.
